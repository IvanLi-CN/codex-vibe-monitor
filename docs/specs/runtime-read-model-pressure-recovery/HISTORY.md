# Runtime Read-Model Pressure Recovery - History

- The Initiative adopts an exact-read-model contract: Summary availability may not be obtained by returning partial, empty or request-time reconstructed data.
- Summary compact admission revealed that legacy failure classification was still reader-derived: payload-aware full aggregation and payload-free compact projection could disagree. The durable contract now requires one revisioned canonical classification, bounded live/archive compatibility materialization and shared reader consumption; raw diagnostics remain confined to that controlled background path.
- A bounded recent index records its first omitted live timestamp; rolling and account windows reaching that boundary fail closed while later fully retained windows continue from memory.
- The newest-N `current` view is isolated from rolling exact-boundary admission so dense historical boundaries do not abort unrelated current hydration; both resident views share one byte budget, and later runtime truncation preserves the newest omitted timestamp rather than relaxing an earlier durable boundary.
- Canonical source-record admission is distinct from resident preview capacity: cumulative raw source payload text does not determine the memory of a retained Summary Projection, and an unadmitted source is represented by an exact range-local unavailable boundary instead of aborting a cold Projection.
- Archive newest-N admission now uses bounded coverage-end proof: a potentially selected but unadmitted archive record fails only its affected scope closed. Historical persisted terminal coverage is likewise separated by global and account rollup proof, preserving global SSE de-duplication when only an account compact bucket lags.
- Global `current` archive admission is evaluated at the requested newest-N cutoff, while historical exact coverage requires both totals and scope usage proof. Current-only persisted terminals that can affect rolling repair are retained in the exact view, and both resident views reserve their shared byte budget before materialization.
- `current` source admission now fails closed when an unrepresented archive could fill a missing requested rank; it does not clamp that rank to the final resident record. Account current treats every incomplete completed archive as relevant until account representation is proven, and archive coverage endpoints include their newest persisted timestamp during hydration.
- Archive coverage distinguishes exact manifest endpoints for current admission from bucket-expanded rolling gaps. Materialized raw boundary replay gaps no longer discard complete durable-rollup interiors, while stale replay identities remain rejected and the materialized legacy marker stays narrowly compatible.
- Bounded archive coverage now uses the same exclusive endpoint for raw replay and compact-rollup proof; equal manifest endpoints remain single-row bounded coverage rather than legacy absence. Current candidate record admission failure is range-local so it cannot suppress an otherwise exact rollup-backed Projection.
- Summary SSE now rejects a cold projection from memory instead of rebuilding through the legacy SQLite path. A current-only archive candidate pruned from the newest-N index no longer pollutes the rolling omission boundary when matching global/account totals and usage rollups already prove that record's compact coverage.
- All-time raw replay now rejects stale SHA markers even when their archive path matches, for both global and account coverage. SummaryCurrent reads its immutable projection and terminal overlay atomically from hub state, and current admission recognizes that the selected cutoff immediately after an unrepresented archive's inclusive final-row endpoint is outside the selected prefix.
- Normal all-time account admission now shares the paged path's completed-manifest proof, preventing an interrupted account manifest from publishing an archive-only account as a fresh zero. Replay markers now retain the completed manifest SHA, so structured usage replay neither falls back unnecessarily nor accepts a replaced archive's stale proof.
- The Initiative records pressure defer as a scheduler state separate from an actual SQLite lock failure, so retry and audit behavior remain observable and bounded.
- Pressure defer keeps durable progress untouched because admission happens before SQLite; its eligibility deadline belongs to the in-memory scheduler, while a persisted real lock failure closes the pressure gate before releasing its permit.
- Coverage repair applies that same permit-scoped lock classification to its repair outcome and all following progress reads and writes, preserving one pressure record and the normal non-lock scheduler failure path.
- A retry-progress lock following a repair lock is one failed coverage attempt, so the persistence-error-first fallback records one pressure event while preserving the original-error fallback for non-pressure persistence failures.
- Coverage repair now returns every permit-scoped SQLite pressure error to the maintenance loop as a deferred outcome, preserving the in-memory pressure deadline and eligibility wake while suppressing task-run audit and generic retry writes; ordinary coverage errors remain visible as failed audited retries.
- The Initiative keeps long-term migration incremental and low priority, preserving durable cursor recovery and P1 writer priority.
- Summary cold start now owns a stable, bounded Legacy Detail Mirror identity sweep before its first Projection build. This prevents pressure-deferred generic backfill from leaving a large `unknown` mirror population in archive admission long enough to repeatedly cancel the whole startup hydration; unresolved files remain fail-closed while independently proven mirrors persist and no periodic Summary refresh races the recovery gate.
- Summary recovery stages Bootstrap publication ahead of all-time reconciliation. Bootstrap can page manifest metadata for compact coverage and finite unavailable proof, but only the all-time checkpoint opens or merges paged raw archive sources. A missing account-manifest proof is retained as an account-scoped unavailable boundary rather than degrading a globally proven compact response. The checkpoint durably commits global/account manifest proof, rollup cursors and aggregate accumulators, so bounded background pages resume after interruption without re-scanning completed history while independently Exact-Ready current and rolling selections remain available from memory.
- Projection freshness renewal now requires the complete generation fence, including both rollup cursors and the settled terminal sequence. A matching fence extends only an immutable in-memory lease; an all-time fence mismatch cancels stale work and hands off a bounded rolling rebuild before stale coverage can publish. Legacy unknown manifest coverage remains scoped to its Shanghai month partition so disjoint historical gaps cannot cause a global Summary outage.
- Checkpoint publication is intentionally separate from deployment; production observation is read-only and begins only after owner confirmation of the exact deployed release.
- Summary readiness has an executable representative-scale contract: a fixed fixture crosses the retired aggregate source boundary, bootstrap and all-time deadlines are asserted separately, and the deterministic oracle runs as a CI-contained PR/Main gate.
- Historical live coverage now publishes as a generation-fenced Projection proof. Rolling refreshes reuse its unchanged overlap and inspect only the bounded ID delta; a late historical source is range-local unavailable until a separate background coverage pass completes, preventing a repeated full historical group-by from exhausting the rolling freshness budget.
- Cold maintenance recovery now retains Bootstrap semantics until the first immutable Projection publishes, so a timed-out cold build cannot silently downgrade later retries to the shorter Rolling budget. Bootstrap tail telemetry is stage-bounded and content-free, and the representative fixture crosses 214 MiB of aggregate raw source text.
- Rolling recovery now consumes a bounded, SQLite-acknowledged Summary Delta Journal for ordinary terminal tail changes. A continuous journal renews the published recent Projection without a complete live admission; capacity or sequence faults become bounded Delta Gap Proofs so only intersecting selections fail closed while all-time remains independently checkpointed. Proof-budget exhaustion retains a broad fail-closed guard, and post-restart terminal replay contributes an exact bounded overlay rather than falling back to full rolling admission.
- ADR 0009 extends the terminal-only in-memory recovery with one durable global
  Source Change Journal and cursor for every generation-fence change. It keeps
  the in-process delta fast path but replaces restart and non-terminal
  full-Rolling fallback with bounded descriptor reconstruction or a recoverable
  selection-local proof. It also makes a compact SQLite Summary Archive
  Snapshot a raw archive cleanup gate, while low-priority legacy backfill
  recovers readable history and preserves irretrievably missing authority as a
  finite unavailable range.
- ADR 0010 separates the historical Coverage Fence from the live-tail cursor,
  keeps raw boundary hydration exclusive to AllTime recovery, and quarantines
  V1 Snapshot pages from cleanup until a semantically verified V2 page exists.
