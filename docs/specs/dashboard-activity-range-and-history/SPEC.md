# 活动总览时间范围与历史活动归位

> 本文保存长期需求；实现覆盖见 `./IMPLEMENTATION.md`，主题边界及兼容背景见 `./HISTORY.md`。

## Context and Scope

- Context: 活动总览同时承载即时运行状态和范围统计，需要明确二者的时间语义，并将长期活动入口放到统计页。
- In scope: 全局总览、上游账号详情复用的活动总览、统计页顶部历史活动日历，以及这些表面的范围、七卡主值、比较和图表联动规则。
- Out of scope: 调用身份、计费、成功/失败分类、Token 分项、真实 TTFT 采样和数据保留策略的重新定义；新增账号筛选器或额外历史指标。
- Contract precedence: 本主题规定活动总览的范围选项、主值与比较口径、次数图时间独立性和历史日历位置。既有自然日七卡与调用时间线主题中的范围绑定约定在这些表面由本文替代；其数值展示、调用布局、分页、容量、错误恢复和清理合同继续适用。

## Terms and Interfaces

- `Statistics range`: 浏览器本地今日、昨日或精确滚动 24 小时区间；决定累计指标和非次数图的数据范围。
- `Live reading`: 当前速率、进行中数量或首 Token 耗时；今日和 24 小时视图使用同一现有实时采样语义。
- `Historical daily average`: 昨日范围内的平均表现；不能用昨日最后一分钟代替。
- `Comparison range`: 今日对应昨日相同本地时间进度，昨日对应前日全天，24 小时对应紧邻其前的完整 24 小时。
- `Live Invocation Timeline`: 与统计范围独立、默认最近 30 分钟的对外调用时间线；账号详情仍按当前账号过滤。
- Interface: 复用现有 summary、rate、timeseries、parallel-work、invocation-timeline 和日历数据边界；具体内部读路径由实现决定，范围和账号作用域必须贯穿每次读取及响应提交。

## Requirements

### REQ-DAH-001

- 全局总览与账号详情活动总览 MUST 仅提供 `今日`、`昨日`、`24 小时` 三个范围，默认选择今日。
- 账号详情 MUST 同步范围、七卡和图表规则，且所有账号数据读取继续应用当前 `upstreamAccountId`。
- 旧持久选择为 `7d`、`usage` 或无效值时 MUST 回到今日；仍有效的今日、昨日和 24 小时选择 MUST 保留。

### REQ-DAH-002

- 三个范围 MUST 使用同一组七卡，主值遵循下表；不得在 24 小时范围切换为另一组汇总卡。

| 卡片     | 今日                  | 昨日                               | 24 小时               |
| -------- | --------------------- | ---------------------------------- | --------------------- |
| TPM      | 实时 TPM              | 昨日活跃分钟均值                   | 实时 TPM              |
| 消费速率 | 实时消费速率          | 昨日活跃分钟均值                   | 实时消费速率          |
| 进行中   | 当前进行中数量        | 昨日平均并行数，标题为「日均并行」 | 当前进行中数量        |
| TTFT     | 实时真实首 Token 耗时 | 昨日真实首 Token 样本均值          | 实时真实首 Token 耗时 |
| 成功     | 今日累计              | 昨日全天累计                       | 最近 24 小时累计      |
| 成本     | 今日累计              | 昨日全天累计                       | 最近 24 小时累计      |
| Token    | 今日累计              | 昨日全天累计                       | 最近 24 小时累计      |

- 成本和 Token 卡标题 MUST 统一使用「成本」「Token」，其范围由活动总览当前选择表达。
- 卡片辅助值 MUST 与其标签及所选范围一致；昨日不能混入当前排队、当前重试或当前每对话值。缺少对应历史依据时 MUST 显示不可用状态。

### REQ-DAH-003

- 昨日 TPM MUST 等于昨日累计 Token 除以昨日有调用的分钟数；昨日消费速率 MUST 等于昨日累计成本除以相同口径的活跃分钟数，不能除以全天 1440 分钟。
- 平均并行数 MUST 沿用完整活动分钟内去重对话数的均值，不能因图表展示 bucket 改变分母；没有活动分钟或无法证明覆盖时 MUST 显示 `—`。
- TTFT 均值 MUST 按真实首 Token 样本数加权，不得用分钟均值的简单平均，也不得回退到首字节或完整响应时间。
- 当前实时采样窗口、更新节奏及严格进行中定义 MUST 沿用既有语义。

### REQ-DAH-004

- 每个范围 MUST 获取对应比较范围；昨日 MUST 接入前日全天数据，不能因为缺少既有接线而永久显示空比较。
- 今日比较范围 MUST 截至昨日相同本地时刻；24 小时比较范围 MUST 为当前滚动窗口之前紧邻的等长窗口。
- TPM、消费速率、TTFT MUST 比较所选范围均值和比较范围均值，角标为「均值环比」。实时主值不得因此变成范围均值，也不引入昨日同一分钟的实时对照。
- 今日和 24 小时的进行中卡 MUST 比较当前数量与比较范围的平均并行数，角标为「较均值」；昨日 MUST 比较昨日与前日的平均并行数，角标为「环比」。
- 成功、成本和 Token MUST 比较两个范围的累计值，角标为「环比」。所有比较 MUST 采用 `(当前值 - 基线值) / 基线值` 的带符号百分比；成功卡不得继续显示相对倍数。
- 比较说明 MUST 可展示实际起止时间和所比较的是均值、当前数量还是累计值。基线为零或任一必要值缺失时 MUST 显示 `—`，不得显示无穷大或虚构百分比。

### REQ-DAH-005

- 次数图 MUST 在三个统计范围中始终使用对外调用时间线，默认展示截至当前的最近 30 分钟并实时跟随。
- 切换统计范围 MUST 不改变次数图的数据范围、实时属性、缩放和平移状态；选择昨日也不得切换为昨日时间线或关闭其实时更新。
- 默认最近窗口 MUST 跨本地午夜连续，不得被自然日零点截断或在午夜重置。
- 时间线 MUST 保留既有缩放、平移、账号隔离、调用身份、状态、并发和 TTFT 表达。手动查看窗口仍必须有界；用户改变账号时 MUST 加载相应账号数据，不得展示前一账号的快照。
- 时间线 MUST 保留既有分页完整性与 loading、unavailable、stale、断线恢复语义，不得回退到聚合热力图。

### REQ-DAH-006

- 活动总览的金额、Token、网速和趋势图 MUST 使用所选统计范围；全局和账号表面必须一致。
- 今日、昨日 MUST 按浏览器本地自然日读取，24 小时 MUST 使用滚动 24 小时范围；时间线的独立最近窗口不得影响这些图表。
- 不同范围的异步响应 MUST 按请求上下文提交，不能把旧范围响应展示为新选择的数据。

### REQ-DAH-007

- 历史活动日历 MUST 从活动总览移至统计页最顶部，位于现有统计筛选与汇总卡片之前。全局与账号活动总览均不再保留「历史」范围。
- 统计页日历 MUST 使用全局统计作用域，严格展示含今日在内的最近 180 个浏览器本地自然日；起始日为今日向前 179 日，不能用六个日历月替代。
- 日历 MUST 提供 `次数`、`金额`、`Token` 切换，默认次数，悬浮展示日期及所选指标值；今日格 MUST 随数据更新。
- 日历的范围和指标选择 MUST 独立于统计页现有时间范围、聚合粒度和活动总览指标选择；统计页原筛选继续控制原有汇总与图表。
- 日历 MUST 保留既有日格展示方式；切换指标不得改变 180 天边界或混入其他指标的值。

### REQ-DAH-008

- 无调用且覆盖完整的范围 MUST 对累计次数、成本和 Token 显示零；均值缺少有效分母或样本时 MUST 显示 `—`。
- 请求错误、覆盖不完整或尚未加载 MUST 保持可识别的错误、不可用或加载状态，不得伪装成已验证的零活动。
- 中英文、桌面和移动布局 MUST 使用一致的指标口径；新增短标签及悬浮说明必须本地化。

## Verification

### VER-DAH-001

- Method: 全局与账号活动总览的范围和主值组件测试、范围持久选择 fixture。
- covers: `REQ-DAH-001`, `REQ-DAH-002`
- Pass condition: 两个表面均只有三档范围和同一组七卡；今日/24 小时使用实时主值，昨日使用日均；累计值来自正确范围；旧 7 日或历史选择回到今日，合法选择保留；账号过滤贯穿所有读取。

### VER-DAH-002

- Method: 均值派生与缺样本 fixture。
- covers: `REQ-DAH-003`, `REQ-DAH-008`
- Pass condition: 12 万 Token 分布于 10 个活跃分钟时 TPM 为 1.2 万；消费速率按相同分母计算；并行均值不随展示粒度变化；1 个 50ms 样本加 3 个 150ms 样本的 TTFT 为 125ms；缺分母或样本显示不可用，已验证的空范围累计显示零。

### VER-DAH-003

- Method: 比较范围、计算及短标签组件 fixture。
- covers: `REQ-DAH-004`
- Pass condition: 今日截至 14:00 只与昨日截至 14:00 比较；昨日与前日全天比较；连续两个滚动 24 小时窗口互不重叠；均值、当前数量与累计比较各取正确输入；2 倍基线显示 +100%，零基线显示 `—`；悬浮说明包含实际区间和比较口径。

### VER-DAH-004

- Method: 时间线状态及跨午夜时钟 fixture、全局和账号交互验证。
- covers: `REQ-DAH-005`
- Pass condition: 切换三档统计范围时最近时间线及手动视窗不变；选择昨日仍接收当前调用；00:10 的默认视窗可覆盖前日 23:40 至今日 00:10；更换账号后没有旧账号残留；已有分页、错误和断线恢复合同持续成立。

### VER-DAH-005

- Method: 图表范围请求、延迟响应和账号作用域 fixture。
- covers: `REQ-DAH-006`
- Pass condition: 四种非次数图均读取当前统计范围及账号；快速切换范围时延迟的旧响应不覆盖新范围；次数图窗口不影响这些请求。

### VER-DAH-006

- Method: 日历日期、指标和统计页组合组件验证。
- covers: `REQ-DAH-007`, `REQ-DAH-008`
- Pass condition: 日历位于统计页首块并展示全局数据，跨月、跨年仍恰好 180 个日期且包含今日；三种指标与日期提示正确，统计页原筛选不改变日历；全局和账号活动总览均没有历史范围；错误和加载不会显示为零活动。

### VER-DAH-007

- Method: 使用受控数据的桌面和移动 Storybook 视觉及交互验证。
- covers: `REQ-DAH-002`, `REQ-DAH-004`, `REQ-DAH-005`, `REQ-DAH-007`, `REQ-DAH-008`
- Pass condition: 三档七卡、昨日标题、比较短标签、独立时间线和统计页日历位置可见且可读；中英文含义一致；比较说明可访问；不同范围、无样本和错误状态没有溢出或错误实时数据。
